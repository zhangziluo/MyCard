# Product Context — 为什么要做 / 解决什么问题

## 问题
- 背单词类 App 普遍**重后端、重依赖**：注册登录、云同步、订阅，且离线不可用
- 通用背卡工具（Anki）功能强但**上手门槛高**：模板/牌组/同步概念多，移动端体验偏工程化
- 大词库导入到网页应用常受 **localStorage 配额**限制（约 5MB）

## 解决思路
1. **纯本地**：数据存 IndexedDB（可容纳 7 万词级），无账号、无网络依赖即可学习
2. **降低门槛**：内置示范词库开箱即用；查词/导入/导出都可从首页一键完成
3. **游戏化闭环**：把「背完」拆成**关卡**（每关 15–30 张，默认 20），通关条件 = 本关卡片全部翻转记忆 + 测试正确率 ≥80%；关卡超过 15 关自动分页
4. **不丢数据**：既能从 CSV/TSV/JSON/**XLSX** 导入（含多文件批量、导入历史回滚、**标准 CSV／JSON 模版**可下载（示例行可选）、**网页内表格录入**且写库前先出**预览/校验报告**），也能导出标准 txt / CSV / Markdown / **JSON（含复习进度）** 与 Anki 卡包，避免绑定

## 目标用户与场景
- 备考人群（中高考/四六级/考研/托福/雅思/SAT/专四专八）：**自备词表**导入后按难度自动编排关卡
- 阅读/看剧遇到的生词：首页输入 → 在线查词 → 一键加入「我的生词」
- 已有 Anki 用户：从本应用**导出 .apkg** 后继续在 Anki 学习

## 关键用户流程
1. **首次打开**：自动导入示范词库（英语高频词 60 词 / 3 关）→ 直接可学
2. **建立自己的词库**：首页「添加单词」面板（单词语/词表/长文本 → 在线查词 → 我的生词）或「导入」按钮/拖拽区（**CSV/TSV/JSON/XLSX** → 预览 → 字段映射 → 选/建牌组；可**多选/多拖批量**各建卡组，先下载**标准 CSV 模版**（示例行可选）或 **JSON 模版**再填；也能用「在网页里填表格」逐格录入 / **粘贴多行**，导入前先看**校验报告**；导入后可在**导入历史**里**撤销**）
3. **学习**：卡组详情 → 关卡列表 → 翻转记忆（四档反馈）→ 本关测试（≥80% 通关）→ 解锁下一关
4. **复习/强化**：整卡组翻转循环（困难词前置）、整卡组可配置测试（20~150 题，题型可配、可选「英英选择 / 多义多选」）、错题优先池、错题专项再练、**明牌配对小游戏 `#/match/{deck}`**（通关 ≥1 关后解锁：**词源可切「整个卡组 / 某一已通关关卡」**，把单词与释义**两两配对**，练「词 ↔ 义」的快速再认——每轮 5 对、一轮一轮配到没有对为止，选「整卡组」就是整库过一遍；连击奖励、全配完结算用时/失误）、**填字小游戏 `#/crossword/{deck}`**（通关 ≥1 关后解锁：**按当前词库交叉排版生成填字棋盘**——词源可选整卡组或任一已通关关卡、每局 6/8/10/12 词、可「换一批」；读线索逐格填字母，检查/提示/显示本词，全部填对结算用时与提示次数）
   - **题型只出「用户能读得懂的语言」（v0.9.1）**：**「英英选择」是唯一「允许出英文题」的开关**——没开它时，卡组里中文释义不足 2 条的词**不会**退化成「英文题面 + 英文释义选项」的多义题，而是换成基础题型；开了它才会用 GCIDE 英文释义兜底。考生若只想考中文释义，不必担心突然冒出英文题
5. **导出**：卡组菜单 ⋮ → 导出 txt / CSV / Markdown / **JSON（含复习进度）** / 导出 Anki 卡包

## 体验与设计语言
- 深色为默认、毛玻璃（glassmorphism）卡片、圆角、克制的氛围光；**浅色主题**于 v0.4.10 引入，v0.4.12 修完弹窗
- 三档明暗（浅色/深色/跟随系统）+ 8 个主色调预设与自定义取色
- 移动端优先：底部滑动手势评分、触控目标 ≥44px；桌面端按断点放宽容器（600 → 760 → 1080 → 1280 → 1440px）
- 文案全中文，状态一律用**可见的即时反馈**（toast / 进度条 / 徽标）表达
- **移动端输入体验（v0.7.0）**：答题只涉及英文单词的场合（填字游戏、填空题）**不唤起系统输入法**——底部弹出**自绘 QWERTY 字母键盘**（含退格；填空题另有空格键），输入框 `inputmode="none"`；可「收起键盘」为右下角迷你胶囊随时唤回；桌面端不显示键盘（用物理键盘），保证「同一套页面两端都顺手」
- **多端（v0.8.0 起，v0.9.0 / v0.9.2 增强）**：数据默认只在本机；需要多设备时，用**自己的** WebDAV 网盘做中转——**词库 + 学习进度 + 复习日志 + 关卡进度**合并成一份，冲突按「内容看最后修改、进度看最后学习」自动化解（**进度只进不退**），删除也可同步且**不会误删**（对方在你删后又改过/背过就保留）。**v0.9.0** 让「上云」更可控：① **只传变化的卡组**（网盘上是「索引 + 每个卡组一个文件」，改一个卡组只传这一个，不再每次整库重传）；② **同步前可以「预览差异」**（只读，先看清会新增 / 覆盖 / 删掉什么、冲突各取哪一端，再决定要不要同步）——降低「一按就把本地/远端改乱」的恐惧；③ **「本机专用」卡组**（不上传、不被别的设备覆盖或删除、本机删除也不外传），让「私人词库 / 临时整理」不必为了同步而妥协。**v0.9.6 再加一条零账号方案**：本机打开 Mycard 时，跑 `python3 scripts/dav-proxy.py` 即可让「页面与网盘同源」（同源根本不做跨域检查），不用注册任何云服务；**v0.9.2 起「连不上」不再是黑箱**：浏览器因为安全限制不肯说原因（只会抛 `Failed to fetch`），于是应用改为**自己给结论**——失败文案带上地址与浏览器原始信息，并可用 **「诊断连接」** 逐步区分「网络不通 / 网盘不允许跨域 / 账号或应用密码不对」，附**坚果云等网盘的填写要点**与**可复制（不含密码）的诊断报告**。这降低了「必须用某个厂商 App 才能跨设备」的门槛，也避免把学习数据交给第三方服务

## 非目标（刻意不做）
- 不做云同步与多设备协同（导出 .apkg 作为跨设备手段）
- 不做社交/排行榜/打卡
- 不引入 UI 组件库或状态管理库
