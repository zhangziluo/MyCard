# Project Brief — Mycard 学习卡片（PWA）

> 最后更新：2026-09-28 ｜ APP `v0.5.6` ／ SW `v1.8.6` ｜ 测试 25 个脚本 / **2093 条校验全绿**

## 一句话定位
纯前端、无后端、**离线可用**的间隔重复记忆应用（艾宾浩斯曲线），用「翻转记忆 → 关卡闯关 → 测试通关（≥80%）→ 间隔复习」的闭环帮助背单词。

## 核心目标（四条主线）
1. **学习闭环**：卡片翻转记忆（重来/困难/记住/轻松）→ 关卡顺序解锁 → 整关测试合格通关 → 按曲线复习
2. **词库进得来、出得去**：
   - 进：内置示范词库、首页在线查词（单词语/词表/长文本 → 生词本）、本地 **CSV/TSV/JSON/XLSX** 导入（预览 + 字段映射 + 目标牌组 + **多文件批量** + **导入历史/回滚** + **标准 CSV／JSON 模版下载**（示例行可选））、**网页内表格录入 `#/editor`**（按模版列逐格填写 + **粘贴多行** + 导入前预览报告 → 同样可新建/追加导入）
   - 出：导出**标准 txt（TSV）**、**CSV（带表头）**、**Markdown**、**JSON（完整，含复习进度）** 与 **Anki 卡包 .apkg**（含 `meta` protobuf + 卡片复习调度）
3. **体验**：移动端优先 + 桌面自适应、深色/浅色/跟随系统、主题色自定义、可安装 PWA、完全离线
4. **工程约束**：**零构建、零依赖、无 TypeScript、无框架**（唯一例外：为生成 Anki SQLite 而内置于 `vendor/sql.js/` 的 WASM 版 sql.js）

## 范围
| | 内容 |
| --- | --- |
| **In** | 卡片（front/back/例句/音标/标签/多释义）、翻转记忆、间隔重复调度、关卡与分页、7 种题型、整卡组可配置测试、难度判定与关卡编排、在线查词、本地文件导入（CSV/TSV/JSON/**XLSX**、多文件批量、历史回滚）、txt/CSV/Markdown/JSON/apkg 导出（含复习进度迁移）、主题与明暗模式、PWA 离线 |
| **Out** | 账号与云同步、多人协作、任何服务端、构建工具/打包器、TypeScript、前端框架（React/Vue）、Dexie 等 ORM |

## 关键约束（不可违背）
- **数据只在浏览器**：IndexedDB 库 `mycard` v2（`decks`/`cards`/`meta`/`lookup`）+ 少量 localStorage（设置与清单）；不向任何服务器上传学习数据
- **零依赖、无构建**：源码即产物，静态服务器直接跑（`<script type="module" src="js/app.js">`）
- **测试可离线跑**：Node 原生脚本 + 自写的最小浏览器 / IndexedDB 桩；不引入测试框架
- **仓库体积**：不入库体积大的本地数据（`gcide-0.51/` 源语料、`data/` 下考试词库），见 `systemPatterns.md` 的忽略策略

## 与用户协作的既定约定
- 需求若来自其它技术栈（Vue/React/TS/Dexie/PapaParse 等），**先确认再适配到本栈**，不照抄
- 每个功能：先给计划 → 实现 → **跑全量回归** → 更新 README → 提交推送
- 提交信息用「类型: 中文摘要（APP vX / SW vY）」格式，正文按模块分段
